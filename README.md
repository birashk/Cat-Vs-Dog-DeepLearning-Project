# Cat vs Dog Image Classification 🐱🐶

This project implements an image classification model to distinguish between cat and dog images using deep learning techniques.

The project was developed as a hands-on practice in **Computer Vision** and **PyTorch**, and executed in the **Google Colab** environment.

---

## 🧠 Project Description

Image classification is a fundamental task in computer vision.  
In this project, a neural network is trained to classify images into two categories: cats and dogs.

The notebook covers:
- Data loading and preprocessing
- Model training
- Evaluation
- Visualization of predictions

---

## 🛠️ Technologies Used

- Python  
- PyTorch

- NumPy  
- Matplotlib
